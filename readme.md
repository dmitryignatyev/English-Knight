# English Quest 2–4

Интерактивный тренажёр по английскому для 2–4 классов.
Поддерживает Spotlight 2–4 + расширение словаря по Cambridge YLE (Starters / Movers / Flyers).

## Возможности

- 🎯 Тренировка по темам с интерливингом (в тест попадают и слова предыдущих уровней)
- 📚 Карточки новых слов с озвучкой и проверкой произношения
- 🔁 Интервальное повторение (SM-2)
- 🧠 Грамматика: Present Simple / Continuous, Past Simple, Future Simple, to be, предлоги, степени сравнения
- 📖 Личный словарик
- 🎯 Еженедельные цели + RPG-коллекция рыцаря
- 🏆 Стикеры за успехи
- 📈 График прогресса
- 🔐 Авторизация через Supabase (опционально) — прогресс синхронизируется между устройствами
